PLUGIN DISCOVERY

How listing requests are handled

Information: We receive your request type, plugin name, listing URL or ID if provided, name/organization, contact email, and requested change. Our Cloudflare backend temporarily derives a hashed hourly abuse-control identifier from the connecting IP address; it does not store the raw IP in the request database.

Purpose: Evaluate publisher requests and review possible changes in Plugin Discovery. We may contact you to clarify or verify publisher ownership. No submission automatically modifies the public plugin catalog.

Processing: Cloudflare Workers and its private D1 database store the request. Cloudflare Turnstile helps prevent abuse. Rules may categorize requests and flag urgent wording for human review. AI inference is not currently enabled. No automated finding is treated as proof of ownership or rights.

Operator alerts: New requests create assigned notifications in a private GitHub repository. Those notifications include only the case ID, request category, and receipt time, not your name, contact email, or request details. Reviewers access original submissions through our protected Cloudflare D1 database. Previous requests submitted through the old FormSubmit form remain in the previous provider/email system and are reviewed separately.

Retention: Our scheduled Cloudflare Worker deletes requests after 90 days and hourly abuse-control counters after 24 hours. Deletion timing depends on the scheduled task successfully running. Cloudflare's infrastructure may apply separate backup and diagnostic retention policies.

Privacy: We do not intentionally publish private contact details or raw request text in plugin search results. We do not require government IDs or passwords; do not submit sensitive personal information.

Scope: We can change Plugin Discovery listings but cannot remove or modify the official OpenAI marketplace listings.
